## Why
最新评审要求逐项分诊 `npm run web:verify` 的五个失败，区分测试夹具问题与产品回归，避免通过删除断言或改变产品阈值来消除失败。

## What Changes
- 对四个前端隔离测试夹具补齐其所依赖的当前手势阈值、Vue 导出和 CSS 导入解析。
- 在旧版迁移测试中仅为当前 API 的数据播种阶段建立临时兼容表；正式迁移前删除该表，继续验证真实旧版 schema 的增量升级。
- 不修改产品运行时代码，不改变断言的业务含义。

## Capabilities
无产品运行时行为变化；使用 `skip_specs`。

## Impact
仅影响五个测试脚本与本 OpenSpec 记录。所有数据库操作使用测试创建的临时 SQLite 文件；不读取或写入正式宿舍数据。
