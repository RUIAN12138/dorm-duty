# Design
activity 全历史投影按完成时间和 id 降序每个任务选择一条，返回既有 key、completed_at 和 assignee_name，沿用宿舍鉴权与修正、撤销过滤。预览使用草稿记录相同规则。ActivitySummary 负责卡片翻面、键盘与读屏语义及暂停轮播，SwipeCardDeck 保留既有跟手和阈值，将短拖恢复曲线调整为轻度弹性并防止拖动触发点击。支持减少动态效果。

翻面追加：卡堆外层继续独立处理滑动；卡片内部先轻微向上、向外抽出，再进行 Y 轴翻转，保持抽出位置以露出下层卡片。返回时先反转，再回到卡堆；每个元素的 transform 仅由一套 CSS 过渡驱动，连续点击可从当前状态反向。轮廓加细荧光边缘和轻柔光晕，随翻转状态淡入淡出；减少动态效果时立即切换且不作抽出位移。

2026-11-04 用户纠正：翻转必须包含整张卡片的底色、边框、阴影和荧光轮廓。ActivitySummary 局部取消卡堆外壳的静态表面，把材质放在正反两面；不改变其他 SwipeCardDeck 使用者。验证增加卡面中间帧投影宽度及静态外壳检查。

实际浏览器体验发现向右抽出会触及容器右侧裁切；改为垂直抽出18px、景深8px，光晕8px，保留原始卡片尺寸与堆叠。
