# Design
自觉完成映射现有 self_round 模式：调度和推送重验只查询 scheduled 任务；邮件投递时再以当前类别模式过滤旧的排队任务，混合任务只保留仍适用的 scheduled 项，手动催促和留言不受影响。无迁移，无数据库批量修改。
滚动条统一用 scrollbar-width 和 WebKit 伪元素隐藏，保留溢出及触控、键盘滚动。页面导航只补充日期列表滚动容器与空状态容器本身的空白命中，控件、记录单元、弹窗、系统边缘和纵向滚动维持原优先级。

定时提醒设置的原说明“只提醒未完成的值日任务”更新为“只提醒按时间安排且未完成的值日任务”，避免自觉完成模式用户误以为仍会定时提醒。

正式 content-stage 真实触摸回归记录到横滑出现 pointercancel：原生滚动容器自身未声明方向，祖先上的 pan-y 跨越滚动边界未生效。将 pan-y 直接设置在列表滚动容器，原生纵向滚动继续，横向交给空白切页。

服务器入口实际加载生成的 push-runtime.cjs 和 email-runtime.cjs，均随对应源码重新构建；推送包内少量第三方模块路径标注因本机依赖位置变化而变化，不改变依赖版本。

后台定时器隔离测试通过现有设置 API 将值日设为按时间安排，轮换周期覆盖两天，以继续验证独立计时、同日重启不重复和次日启动补发；不更改断言或正式数据。
