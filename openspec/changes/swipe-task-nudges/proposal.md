# Why
用户明确“给抬水页改为催促页，大字区域左右滑动可以切换催促其他任务，逻辑保持一致，球球提示，不做明显切换按键，微移露出下一任务”。此条授权对应正式第二页和导航展示，不迁移旧数据。
# What Changes
第二页改催促，横滑大字任务名切换当前启用任务；初访轻量边缘预示，球球提示，键盘与减动效降级。保留既有敲击反馈、同一发送API和服务端限流、本人抬水/撤销/详情/临时安排入口。只读board增加当前催促任务集，创建预览同源。
# Capabilities
## New Capabilities
- `task-nudges`: 无明显切换按钮的多任务催促。
## Modified Capabilities
第二页展示由抬水专项改为催促，内部water路由/ID保留；旧宿舍数据和任务配置不迁移。

限定NudgePane及ChoreBoard第二页接线、WaterNudge可访问文案、导航第二页标签、球球提示、board只读结果、创建预览数据与相关隔离测试。无真实邮件AI、无生产数据库操作。本轮不PR、不合并、不发布。
