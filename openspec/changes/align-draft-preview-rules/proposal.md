# Why
用户要求持续改进创建、引导及真实组件预览，并完善后端架构；本轮禁止PR与发布。源码确认草稿预览无条件开放can_complete、软性任务显示截止时间、轮次和任务状态矛盾。
# What Changes
将现有完成权限与配置映射的纯计算提取到现有共享配置模块，后端保持原规则；创建专属预览数据适配使用相同规则，并生成一致任务/轮次/日历样本。仅复用正式UI，不修改正式页面、教程业务或宿舍数据。
# Capabilities
## New Capabilities
- `draft-preview-rules`: 正式规则一致的隔离预览模型。
## Modified Capabilities
无对正式权限语义的修改。
# Impact
限定共享配置、chores后端纯函数调用和创建专属预览适配与同目录测试。所有模拟成员/任务为负ID，不含令牌、网络、持久写入；无迁移。不创建PR、不合并、不发布。
