# Design
范围仅CreationProgress.vue、新增创建进度专项脚本及本change。creationMode=false保持原参数和CSS。
轨道内标记使用6×4px圆润短槽，当前步骤轻微扩大，保留五个无标签按钮及44px命中区。不是大圆节点、数字或外部装饰。
拖动坐标以指针原始位置计算页面意图，显示位置仅在整数步骤附近以连续二次衰减函数轻微吸引，不能更改选中阈值或重复触感。只在creationMode启用。
X位置由现有Motion数字弹簧/paint驱动，显隐及局部形变由原CSS transform/opacity控制；拖动形变短过渡，位置不延迟。释放以屏幕可见精度收尾，不等待亚像素尾段；新按下取消旧弹簧和完成回调。减少动态效果直接终态。
验证真实页面的中间帧、吸附/反向/取消/连续重按、无额外震动、深浅色/减动效和工作台保持；浏览器模拟不冒认真机。
