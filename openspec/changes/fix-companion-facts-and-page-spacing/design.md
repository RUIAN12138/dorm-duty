## Decisions
保持正式组件结构。身份栏下移约10px，任务锚点使用统一小幅 lift，并在短屏减小。布局和导航分别验证。

聊天仅在真正冷打开记录 window scrollX/Y；关闭时在 DOM 卸载和原生锁释放后即时恢复，晚到 viewport 事件复用既有订阅。重开/卸载废弃旧恢复任务，不新增固定键盘高度/延迟。

事实回答使用当前成员 ID 校验后的实时 board/activity，区分自主轮次已完成与今日打卡。走原有幂等、限流、身份复核与聊天存储路径；不调用模型猜姓名或安排。普通对话把当前身份放到首个系统指令，识别叫成其他有效室友的明显称谓时回到已验证本人快照。不宣称彻底消除所有生成模型幻觉。

## Validation
隔离SQLite和模拟模型验证身份切换、旧错误历史、任务完成/撤销实时变化、抬水轮换、提醒路径、无权限冒领。浏览器测前后锚点、聊天焦点导致的页面偏移恢复及重新打开、窄屏与减动效。iOS实体偶发偏移须真机复测，不把模拟通过说成已确认根因。
