# v71：室友姓名、页面手势与键盘退出

本轮只修改消息标题层级、主页面左右滑动判定、球球长按和聊天退出定位。不修改配色、字号、页面排版、任务规则、历史数据、设置导航或已有完成反馈。

| 原行为 | 本轮行为 | 原因 |
| --- | --- | --- |
| 留言卡片大标题是「室友留言」 | 大标题显示发送者姓名，小标题保留留言／任务类型 | 直接辨认谁发来的消息，正文、时间与已读操作保持原位 |
| 页面滑动排除所有按钮 | 完成按钮、抬水姓名等普通按钮区域可起手切页 | 手指横移后屏蔽合成点击，避免误打卡、误催促；专属月份、任务和记录手势保留优先级 |
| 子元素丢失隐式指针捕获会取消父级手势 | 只响应当前手势持有者的捕获取消 | 兼容移动浏览器从子元素向页面交接指针的过程 |
| 长按漂移超过 10px 就取消 | 保留 380ms 激活，允许 18px 轻微漂移，显式捕获指针 | 减少手指轻微晃动造成的失效；大幅移动或取消仍不打开聊天 |
| iOS 可对球球内部元素触发文字选中／呼出菜单 | 球球及渲染子元素禁止选择、系统呼出菜单，成功长按不泄漏留言点击 | 限定球球区域，不影响聊天正文的正常选择与滚动 |
| 键盘打开时按旧坐标回位 | 冻结聊天视口，实时追踪主页面球球的位置与大小，键盘恢复后交接 | 避免视觉视口高度／偏移变化与收起动画叠加造成错位；短暂等待有上限，减少动态效果时直接退出 |

回位只驱动球球自身的 transform，保留原来的表情状态交接、内容反向退出、背景恢复与手势返回。关闭中重新打开仍受同一代次保护，旧动画不能卸载新聊天。

## 验收

- `DORM_CONTINUITY_QA=1 node scripts/check-companion-chat-browser.mjs`：Chromium 使用原生触摸事件，从完成按钮和抬水姓名起手，双向切换三页；核对没有误打卡、误催促；长按轻微漂移、文字选择抑制、延迟留言不泄漏。
- 同一脚本默认分支：按帧模拟键盘高度与偏移恢复，检查回位中间帧及最终落点、普通退出时长、输入、服务失败、键盘导航和减少动态效果。
- 对应 WebKit 两分支：验证 Safari 引擎中的回位、手势、原有设置与主题动画。
- `node scripts/check-sheet-banner-polish.mjs`：姓名大标题，正文、时间、已读保留；自动收起和长按回复不回退。
- 类型检查、前端状态回归、生产构建、页面退出残留与原完成反馈回归。

浏览器中的触摸与视觉视口模拟不等同于真实 iPhone 输入法及系统手势验收。发布包只含代码；发布前备份，并核对既有打卡、历史修正、邮箱绑定和聊天记录摘要。
