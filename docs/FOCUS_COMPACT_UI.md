# 聚焦任务与一屏日历

## 1. 背景

用户要求值日、抬水恢复 v32 的黑白大字页面；抬水可播放姓名交接老虎机。日历更紧凑，热力图并入日期格；列表去掉顶部次数显示；统计改为类似 iMessage 多张图片的叠卡切换，不再向下铺四类内容。

## 2. 当前仓库状态判断

从 main `1283c95` 开始，分支 `codex/restore-focus-compact-calendar`。保持 Vue 3、Vant、Motion for Vue、Reka UI。v33 的历史修正、权限和统计接口继续使用，无后端规则或数据库迁移改动。

## 3. 本轮目标

| Before | After | Why |
| --- | --- | --- |
| 三行信息任务卡 | 恢复提示语、大任务名、单个完成按钮 | 用户更喜欢之前的大字聚焦风格 |
| 完成后任务沉入折叠组 | 恢复完成按钮的已完成态，再点撤销 | 与原有任务页一致，仍能纠正误触 |
| 抬水姓名静态展示 | 实际交接后，首次看到时播放一次滚动姓名 | 表达负责人交接，不随机决定负责人 |
| 月历和独立三月热力图重复占空间 | 日期格深浅表示打卡密度，并保留人员/任务标记 | 一张月历同时表达日期、密度与完成记录 |
| 列表顶部五天次数条、整月长列表 | 去掉次数条，使用按剩余高度分页的记录列表 | 人、任务、日期、时间在当前页可读 |
| 四类统计纵向堆叠 | 单张聚焦，后方两张错位预览；左右滑动、箭头或分页点切换 | 类似多张照片的浏览节奏，无需上下翻长页面 |
| 分段器隐藏面板参与 flex | 明确隐藏非活动面板 | 避免隐藏布局挤压日期格、导致标记越界 |

## 4. 修改范围

- ChoreBoard 恢复 v32 的值日与抬水布局，保留新版本权限、错误恢复与历史能力。
- WaterHandoffName 复用已有去重逻辑，每设备/成员仅消费新交接事件一次；首次升级跳过旧事件。
- CompactRecordList 按可用高度计算每页1–5条，左右翻页或箭头；点击记录打开当日详情。
- SwipeCardDeck 负责统计叠卡的跟手、方向判定、松手切换、越界回位、键盘和减少动态效果处理。
- ChoreCalendar 按视口与底部导航的实际位置确定高度；六行月份固定，保留连续滑月。

## 5. 禁止事项

不修改值日自由轮次、抬水顺序、完成/撤销权限、历史修正日志、邀请入口或推送配置。不删除任何真实记录。不把老虎机当成随机排班：结果始终由服务器确定。

## 6. 具体实现与参考

技能：frontend-design、emil-design-eng。参考本机 `react-bits/src/content/Components/Stack/Stack.jsx` 的叠放与交互组织思想，使用 Vue 自行实现，没有复制 React 组件或新增依赖。指定的 awesome-design-md / math-curve-loaders 目录当前不存在。

主任务页恢复原先视觉层级，完成按钮56px、最大300px宽；动画仍在固定布局内处理 transform/opacity。姓名滚动沿用1.7秒加减速与停稳过程，作为用户特别指定的交接反馈；不恢复游戏计分或假催促次数。催促触感局部变形，不压缩整页。

日历热度由该日真实记录数量计算，不另加数据源；日期格保留成员像素标记、值日/抬水区别及记录小点。完整月份始终可见。详细记录和历史修正仍放在抽屉中，详情内容多时允许抽屉滚动。

统计保留近三月四类总数、本轮完成率和连续日期统计，只改变呈现方式。每次一张卡可交互，其余卡 inert；横向手势不触发底部页面导航。只用 transform/opacity；减少动态效果直接呈现结果。

一屏目标为常见竖屏手机 320×568、390×667、390×844、430×932。记录数量无上限时通过分页访问全部记录，不能将整月记录硬塞进同一屏。极端横屏、系统放大文字时优先保持内容可达。

## 7. 验收标准

- 值日、抬水恢复大字界面；打卡有回执反馈，完成后可再次点击撤销。
- 新交接事件在各成员首次看到时播放，切页/刷新/撤销旧交接不重复播放；减少动态效果跳过。
- 四种竖屏尺寸下，完整月历、列表当前页及统计卡位于底部导航上方，不依赖页面纵向滚动。
- 热度、日期、人员和任务标记一致，密集标记不越出日期格。
- 列表无顶部次数条；分页不遗漏记录，点击可查看与修正历史。
- 统计卡能跟手左右切换，边界回位，箭头/分页点/键盘可用；只有当前卡可被操作。
- 切换任务和页面、长按排序、持久化身份、错误恢复、系统减少动态效果均保持可用。

## 8. 验证输出

`check-focus-compact.mjs` 覆盖真实隔离后端的完成/撤销、历史补改、密集记录分页、四尺寸一屏布局、叠卡手势与统计口径。结合已有交互79项、交接20项、排序边界、连续滑月和双浏览器持久化回归。截图和报告位于被 Git 忽略的 `docs/evidence/focus-compact/`。浏览器模拟不能替代物理设备帧率、触感或通知送达验收。
