# 本地版使用与验收

2026-10-12：根据用户「目前无法切回，先完成本地版本」的决定，公网发布暂停。当前版本在这台 Mac 上运行，前端为 Vue 3，业务代码复用 Cloudflare Worker，本地存储为文件 SQLite。网站和 API 使用同一个 8081 端口。内容分为值日 `/`、抬水 `/water`、日历 `/calendar` 三页，底部导航切换，所有正式成员可完成本人任务及定向提醒室友。

## 启动

双击项目根目录的 `启动.command`。也可以运行：

```bash
cd /Users/apple/project/dorm-duty
./scripts/local.sh
```

电脑入口是 <http://127.0.0.1:8081/>。终端打印 `同一 Wi-Fi 手机入口`，手机连接与 Mac 相同的 Wi-Fi，在 Safari 打开该地址。本次正式服务核对的地址为 <http://192.168.2.60:8081/>；换网络或 IP 后，以本次启动日志为准。手机的 `127.0.0.1` 指向手机自身，不能连接 Mac。

服务运行时保持启动终端开启，Mac 保持联网和唤醒。按 Ctrl+C 停止，再次双击即可恢复。再次启动同一个数据库时会复用已有服务，不会另建空数据库。端口被其他服务占用时会报错，不会自动停止其他进程。

一键启动需要 Node.js 22.13 或更新版本和 npm。依赖缺失时自动按锁文件安装；首次或停止后启动会完成前端类型检查、生产构建和 Worker 资源嵌入。本机依赖已准备好。

## 验收顺序

1. 首次打开看到「先找到你的宿舍」。选择「创建宿舍」，填写宿舍名、自己的名字和室友名字，选择自己的像素标记；无需账号密码。创建成功后，本浏览器保存创建者管理凭据。
2. 「值日」`/` 显示本人今天的地板、厕所和洗手池任务；没有当天任务时显示最近未来任务。底部「抬水」切到 `/water`，显示当前负责人及顺序；底部「日历」切到 `/calendar`，查看完成标记。确认身份前隐藏底部导航。三页共用「室友消息 N」抽屉入口；发送提醒和任务设置仅在值日 / 抬水页，日历页只保留月份与记录。创建者打开「自定义任务」，分别设置四类内容、时间和顺序；地板 / 厕所 / 洗手池可额外设置值日星期及连续负责天数。
3. 在另一浏览器或手机选择「加入宿舍」，输入邀请码，选择自己的名字和未被占用的像素标记，再确认进入。该浏览器领取绑定本人的成员令牌，可以完成本人任务、发送及接收提醒，但没有创建者管理权限。
4. 本人点击「我已完成值日」，当前抬水负责人点击「我已抬水」。服务器记录完成时间；抬水只推进一次至下一位，其他浏览器刷新可看到新负责人。重复点击、代打卡、未来任务打卡被拒绝。
5. 从底部进入「日历」，点击完成过任务的日期，查看人员、任务和服务器记录的时间。同一天多人完成会显示各自图案，更多图案通过数量提示和日期详情查看。日历采用上海时区的实际完成日期，补做前一天任务时会标在实际完成当天。
6. 在值日或抬水页点击「提醒室友」，选择室友和其未完成任务。对方打开网页、手动刷新或页面定时刷新后通过「室友消息 N」打开抽屉查看站内提醒，可标记已读。同一发送人、接收人、任务一分钟内只允许提醒一次。系统锁屏通知尚未开通。
7. 创建者修改设置后，地板 / 厕所 / 洗手池只重排明天起的未完成安排，今天和完成历史保留。抬水修改内容 / 截止时间会更新当前任务，仍由当前负责人完成本轮；设为未来开始时，开始前不能打卡。关闭某类任务后不能继续完成或提醒该类任务。
8. 分别直接打开或刷新 `/`、`/water`、`/calendar`，检查路径与成员身份恢复，返回 / 前进仍对应正确页面。停止服务再启动，检查邀请码、三类设置、当前抬水轮次、图案和完成记录仍存在；创建者在当前浏览器仍可管理。

「先用游客模式体验」只展示独立的六人示例，有游客标识，不能完成、发提醒或改配置。游客示例只初始化一次，重启不会反复添加默认成员或重置示例宿舍。

详细业务、接口与权限见 [CHORES](CHORES.md)，图案来源见 [MEMBER_MARKS](MEMBER_MARKS.md)。

## 浏览器与数据保存

正式本地数据为项目内 `data/dorm-local.db`。运行时 SQLite 还会创建 `-wal` 和 `-shm` 文件，数据库启动锁为 `.server-lock`。简单备份应先正常停止服务，再复制数据库到另一位置；运行中备份需使用 SQLite 一致性备份 API，不能单独复制主数据库。

本轮迁移前已使用 SQLite 备份 API 保存 `data/backups/dorm-local-before-chores-20261012T075755Z.db`，完整性检查通过。新增迁移 `site/drizzle/0001_far_crusher_hogan.sql` 为三类任务、成员身份、图案和提醒新增表；已应用的 `0000` 不改写。正式服务已升级至两条迁移，七张旧业务表与备份逐行一致，当前只保留游客示例，没有自动化测试创建的正式宿舍。旧 FastAPI 的 `data/dorm.db`、旧 QA 的 `data/qa.db` 与新版独立，不会自动混用或导入。

服务器保存宿舍、任务、标记、提醒和会话哈希；浏览器保存所选成员、成员令牌及创建者设备凭据。重启服务器保留数据，清空网站数据会丢失本浏览器凭据。成员可以重新用邀请码选名领取成员身份，邀请码不能恢复管理员权限。

这是一种信任式选人入口，不验证选择名字的人是否本人。知道邀请码的人可以领取该名字的成员权限；领取创建者名字也不会获得管理权限。请在宿舍熟人之间使用邀请码。

`127.0.0.1`、局域网 IP、不同端口以及不同浏览器的存储彼此独立。主要用手机管理时，请在手机 Safari 的局域网地址创建宿舍，并继续使用同一地址；电脑上的管理身份不会自动传给手机。局域网 IP 更换也会改变浏览器站点来源。

## 开发检查与可选配置

```bash
# 全部使用独立测试数据，不写正式宿舍数据库
node site/scripts/check-cloud-backend.mjs
node site/scripts/check-chores.mjs
node site/scripts/check-worker.mjs
node scripts/verify-local-persistence.mjs
node scripts/verify-chores.mjs
```

要开发当前 Vue 页面，保持 `8081` 持久 Worker 开启，另开终端：

```bash
cd /Users/apple/project/dorm-duty/frontend
DORM_API_ORIGIN=http://127.0.0.1:8081 npm run dev
```

Vite 的默认 API 目标 `8000` 为原 FastAPI，未实现新版 `/chores`；当前四类任务开发应明确设置上面的目标。`scripts/cloud-preview.mjs` 是独立内存 QA 预览，重启丢弃数据，不是日常启动入口。原 `scripts/dev.sh` 保留作为 Python 后端开发参考。

本地启动支持环境变量，不需要编辑 `.env`：

| 变量                  | 默认值               | 用途                                             |
| --------------------- | -------------------- | ------------------------------------------------ |
| `DORM_LOCAL_PORT`     | `8081`               | 更换服务端口                                     |
| `DORM_LOCAL_HOST`     | `0.0.0.0`            | 允许同一局域网访问；只在本机使用可设 `127.0.0.1` |
| `DORM_LOCAL_DATABASE` | `data/dorm-local.db` | 独立指定数据库；换路径会使用另一套数据           |
