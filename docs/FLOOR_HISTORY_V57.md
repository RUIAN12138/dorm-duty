# v57 地板重新打卡与旧历史修正

## 真实根因

用户反馈只有地板不更新。此前查询时尚无当天地板写入；后续李豪重新打卡后服务器已保存当日完成时间，但同一task_id关联的旧chore_history_entries仍指向10月16日。原historySQL无条件COALESCE修正时间，导致日历落到旧日期。该机制与类别无关，现有地板数据触发了它。

## 修复

历史投影只在修正updated_at >= 本次任务completed_at时应用修正日期或voided标记。撤销后重新完成复用task_id，但新completed_at使旧修正失效；日历、列表、统计与历史详情统一使用投影。保留修正原值、audit及revision，后续新修正继续递增并保留并发冲突保护。无数据库迁移，无补记、删记录或改写真实历史。比较使用julianday兼容时间格式。

## 今日圆形

用户要求从框线改为稍大实心圆。圈最大32px，由日期按钮容器可用宽高决定，四周至少2px余量；日/夜沿用主题前景/背景，按钮热力色仍保留。短屏不挤动日期、不越格。

## 验证

- 新API回归106项：floor/toilet/sink/water真实完成→修正→撤销→重打，旧日期和void不影响新完成，新的修正仍有效，审计与revision不丢、过期草稿409。
- 真实ChoreBoard浏览器预置旧地板修正，重打后热力格和详情即时更新；服务器回读仍在今天、撤销清除。Chromium/WebKit各9项。
- 日期圆形在320x568/390x844/430x932中检查实际边界/圆度/填充，原主题/颜色/卡片回归43/44项。
- 发布前备份与行哈希比较，健康和公网版本校验；不将隔离测试称为实体手机验收。
