# 恢复触感、折叠记录与间隔提醒

## 1. 背景

用户明确指出 v34 恢复不完整：催促反馈被弱化、列表折叠丢失、抬水位置偏上、值日详情仍从中间 morph。要求恢复原交互，统计改为距上次完成的时间，日历只保留热力图，并且每项任务可单独设置提醒间隔。

## 2. 当前仓库状态判断

从 main `abb238b` 开始，分支 `codex/restore-motion-recency`。保留 Vue 3、Vant、Motion for Vue、Reka UI；沿用原始任务、历史修正投影和成员授权。

## 3. 本轮目标

| Before | After | Why |
| --- | --- | --- |
| 催促仅小幅压缩、无浮字 | 恢复原有姓名局部弹性、波纹与「催促 +1」 | 恢复用户认可的木鱼式触感；网络发送仍有去重 |
| 抬水顶部锚定 | 在可用任务区居中，主体字号60–84px | 保持黑白大字视觉中心 |
| 值日 shared morph | 与抬水相同的 bottom 抽屉 | 统一进入与拖动关闭方向 |
| 列表逐条平铺 | 按日期折叠，历史日期默认收起，依次渐入展开 | 恢复层次，不增加顶部次数条 |
| 次数、完成率、连续天数卡 | 每类任务距上次完成多久、实际完成时间 | 直接提供卫生间隔提醒 |
| 箭头切换卡片，后卡突然替换 | 区域内左右拖动，邻卡提前可见，速度投影后吸附 | 消除生硬切换；键盘左右键仍可用 |
| 日期格内小头像、任务标记和小点 | 纯热力格，点击查看人员、任务和时间 | 简化日历视觉 |

## 4. 修改范围

ChoreBoard、WaterNudge、ChoreCalendar、CompactRecordList、SwipeCardDeck、ActivitySummary、ChoreSettings，以及活动查询与分类配置。新增 `0011_task_reminder_intervals.sql`，只加 `reminder_interval_days` 列，不改既有任务或历史。默认3天，创建者可分别改为1–365天。

## 5. 禁止事项

不重排或重写完成历史；不修改自由轮次、抬水顺序、成员身份、推送凭据。催促「+1」是本机触感次数，不表示每次都发送一条通知；后端60秒去重保持不变。卡片颜色不等同于逾期，也不新增自动推送。

## 6. 具体实现与参考

技能：frontend-design、emil-design-eng。读取本机 React Bits `Stack.tsx` 和 `Carousel.tsx`：参考卡片缩放、邻卡跟手可见、速度与吸附处理；以 Vue 和 transform 弹性回位自行实现，没有复制 React 代码或新增依赖。Galaxy 已有六类适配见 `UIVERSE_COMPONENTS.md`；额外查看的 0senno 社交卡不适合本界面，没有照搬。指定的 awesome-design-md、math-curve-loaders 目录仍缺失。

活动接口新增 `last_completed`，基于完整有效历史按分类取最新时间，包含历史修正与补记，排除被撤回记录。沿用宿舍隔离授权；不依赖近三月 daily 数据推断“上次”。前端每分钟更新相对时间。达到该项提醒间隔为淡橙，达到两倍为浅红；从未完成为独立空态。卡片保留上次实际时间，颜色不是唯一信息。

历史列表继续使用 RecordTimeline 的叠层、交错入场与今日自动展开。跨日后昨天自动折叠；按日期分页保留全月访问，展开过多条时在列表内部滚动，不拉长整页。编辑、审计与撤销权限不变。

## 7. 验收标准

- 抬水居中、姓名大字，点击催促产生局部回弹、波纹、浮字，整页不缩放。
- 值日和抬水详情均从屏幕下方进入，可下拉关闭。
- 统计无箭头按钮；手指尚未松开时邻卡已连续显示；松手吸附，底部页不误切。
- 四类间隔分别持久化，普通成员不可更改创建者设置；越界、非整数、跨宿舍请求拒绝。
- 超过三个月的最后完成记录、修正和撤回均正确反映在卡片；不改变当前轮次或抬水人。
- 日历只显示日期与热力深浅，点击日期有完整人员详情。
- 历史列表恢复默认折叠和逐项展开，所有历史记录可达。
- 四种手机尺寸不出现整页多余滚动；统计实际完成时间不被卡片裁掉。
- 减少动态效果、键盘、失败恢复与身份保持继续可用。
