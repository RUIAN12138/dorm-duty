# v53：版本提示、主题恢复与局部间距

## 本轮范围

只修改五项用户指定内容：新版本独立提示弹窗、顶部随主题同步、恢复原按钮原点圆形主题展开、日间棕黄/夜间灰白统计卡片、值日/抬水操作区与轮次适当下移。标题位置、列表折叠、统计自动播放、完成/撤销、圆环/+1、抬水交接、权限、轮序与接口不变。未来修改必须限定用户当轮范围，不以移除其他已验收交互解决问题。

## 实现

- 沿用现有 Reka Dialog、黑白弹窗与缩放回弹；每个服务器发布包把完整 release name 注入前端。确认后按版本在本机保存展示回执；旧版本回执不抑制新版本。输入中、后台和已有抽屉/弹窗期间延迟展示。PWA 发现等待安装的新版本时另显示「发现新版本」，可更新或稍后；更新失败可重试，不自动刷新已填写表单。
- 发布命令 `npm run web:release -- <唯一版本名>` 自动注入版本；每次发布应更新 ReleaseNotice 的本次变化清单。开发与普通测试构建没有发布版本名时不自动弹已更新提示。
- 恢复 v51 的 320ms 按钮原点圆形展开、混合隔离与快速反向中断；保留 v52 的静态 WebGL 缓冲及暗色镜片。View Transition 更新阶段暂停渲染，不能等待 RAF；只等待 Vue nextTick，再同步绘制新主题玻璃供快照使用。无 API 时保留原轻过渡，减少动效/键盘/后台直接到终态。
- theme-color、根页面及安全区背景跟随当前主题；启动脚本在 Vue 加载前同步初始主题。iOS 添加全屏及透明状态栏元信息，由现有 safe-area 留白承接；浏览器模拟不证明实体手机系统状态栏表现。
- 日间默认连续色带从 #fff8ed 到 #b98a48；夜间从 #f2f2f2 到 #b0b0b0，不继承日间自定义色相。保留原日间颜色设置与服务器任务间隔，v52 默认灰色配置迁移至棕黄默认，自定义色保留；未知日期仍显示暂无记录。文字自动选黑/白保持对比度。
- 仅在页面内容区高于400px时给操作区/轮次增加局部间距；标题锚点不改，短屏与键盘空间不足时沿用紧凑布局。

## 验证

`check-theme-check`：系统/存储变化、320ms圆形展开配置、反向中断、主题色同步与减动效。
`check-stats-palette`：默认/迁移/自定义保存与10000个连续深度、文字对比度样本。
`check-theme-stats-polish`：真实隔离 Vue/SQLite、实际圆形中间帧、日夜/快速切换与玻璃、两套卡片配色、局部间距、320/390/430px抽屉、原列表滚动与统计自动播放。
`check-release-notice-browser`：真实 Vue/Reka 弹窗中间帧、版本回执/重开、更新失败重试/稍后、输入保护、窄屏与减动效。
保留原完成反馈、历史、身份、邮箱与业务回归。本轮不向正式宿舍写入测试记录，不发送真实通知/邮件；实体手机状态栏、GPU帧率仍需真机验收。
