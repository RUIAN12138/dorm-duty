# 验收清单

全部项目初始为待验证。执行后逐项填日期、命令 / 操作、结果与证据路径；失败记录复现方法，不能以构建成功替代手机验收。

## A. 自动化与本地接口

| 场景 | 预期 |
| --- | --- |
| 空数据库迁移 | `alembic upgrade head` 成功；重启不丢账号与任务 |
| 账号注册 / 登录 | 密码哈希不等于明文；重复账号 409，错误凭据 401 |
| 鉴权 | 无令牌 / 过期令牌 401；前端跳登录；刷新恢复本人身份 |
| A 建宿舍、B 邀请加入、C 在另一宿舍 | A/B 可见相同宿舍；C 不能读取 / 改写其数据 |
| 并发加入两个宿舍 | 最多一个有效成员关系，另一个请求 409 |
| 生成排班 | 30 个连续日期符合顺序；同一请求两次不重复或清空记录 |
| 配置合法性 | 重复 / 外宿舍 / 退出成员、过去生成、范围超限均拒绝 |
| 成员变化 | 今天与历史不变；未来退出成员不再被安排；重排影响范围明确 |
| 手工排班 | 普通生成保留手工安排；显式重排只覆盖允许范围 |
| 管理员与退出 | 普通成员不能改顺序；管理员先转移；今天未完成执行人退出 409 |
| 完成任务 | 本人成功，别人 / 管理员代打卡失败；未来任务不能完成 |
| 重复 / 并发打卡 | 一次成功一次 409，completed_at 不被覆盖 |
| 跨午夜与截止边界 | Asia/Shanghai 日期正确；截止前后 display_status 正确 |
| 逾期打卡 | 保存真实时间，返回 is_late，历史显示逾期完成 |
| 昵称变更与退出 | 过去任务的昵称 / 任务快照及完成时间不变 |
| 提醒时钟注入 | 前日 21:00、当日 08:00、19:00 各生成一次；扫描重复无重复消息 |
| 提醒抑制 | 完成任务、退出成员、被调整旧执行人不收到后续提醒 |
| 调度恢复 | 60 分钟内补查，超窗不补发；重启不重复站内消息 |
| 推送状态 | 模拟成功 / 超时 / 410；逐设备记录、有限重试、失效停用 |
| 推送归属 | 用户不能取消 / 读取他人订阅，换账号不沿用未验证旧订阅 |
| 代码检查 | 前端 typecheck / build，已有 lint，后端有意义的权限、事务、排班测试通过 |

并发测试使用独立数据库连接 / 会话触发真实冲突；不能仅连续调用两次并称为并发验收。提醒测试注入业务时钟，不修改操作系统时间。

## B. 浏览器与跨客户端

1. 两个独立浏览器上下文使用 A、B 账号，邀请码进入同一宿舍；管理员生成排班，B 刷新可见。
2. 今日本人打卡后另一个上下文刷新显示同一服务器完成时间；重复点击提示冲突而不改时间。
3. 刷新 `/schedule`、`/history`、`/profile` 可恢复页面；身份到期正确跳登录。
4. 重启后端再访问，账号、成员、排班和历史保留。
5. 检查 320、375、390、430、768 px 的登录、宿舍、首页、日历、历史、我的页面，无横向溢出；表单键盘打开仍可操作，底部导航不遮挡末尾内容。
6. 未加入、空排班、网络失败、加载中、完成 / 逾期和通知不支持等状态可见，按钮不会伪成功。
7. 两台手机重复上述业务同步步骤，记录机型与浏览器版本。桌面两个上下文通过，仅代表浏览器闭环通过。

## C. HTTPS、iPhone 与通知

1. 记录真实 HTTPS 地址、iPhone 型号、iOS 版本、测试账号，不填写真实密码。
2. Safari 登录并完成业务操作；通过系统入口加入主屏幕，从图标重新打开，确认独立模式和图标。
3. 主屏幕 App 点击“开启通知”，系统授权成功；拒绝权限时显示设置引导，页面加载不主动弹权限。
4. 关闭网页、锁屏，发送本人测试 Push，记录真实收到时间；点击通知进入同源正确页面。
5. 对未完成任务验证三个时间点；已完成任务不再收到后续未完成提醒。记录专注模式、系统通知权限等影响因素。
6. 退出登录 / 关闭通知 / 退出宿舍后确认本设备订阅与未来提醒行为；共享设备换账号无他人提醒。
7. 离线打卡不成功；SW 不缓存用户 API；新版本更新不会在表单提交时强制刷新。

后端 accepted 状态、Mock Push、浏览器 permission=granted、Manifest 构建成功，都不能替代第 4 项真实锁屏接收。

## D. 发布与运维

- 持久化数据路径、备份路径、API 与唯一 worker 启动方式明确；同时启动多个 API worker 不启动多个调度器。
- 清洁数据库可迁移；备份恢复在单独临时数据库演练，不覆盖用户数据。
- HTTPS 下 SPA 深链接、API 代理、SW scope、health 正常；密钥不入仓库、不入前端产物、不写日志。
- PostgreSQL 若未经实际运行，标“兼容设计完成，迁移未验证”；不要标已支持生产运行。
- 填写 ROADMAP 证据；任何缺少设备或环境的验收项保留待验证。
