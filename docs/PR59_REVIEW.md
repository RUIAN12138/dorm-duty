# PR #59 合并前回归

本轮保留 PR 的球球、设置收纳、局部玻璃导航和通知、单屏布局、主题切换与日期分页，不回退为旧界面。

## 修复

- `ChoreBoard` 恢复已加载安排的离线/刷新失败提示与重试。读取失败保留当前任务和身份。
- `ChoreCalendar` 只在固定高度的 ScreenStage 中继承父容器高度。普通容器按视口和底栏顶部计算可用空间，避免 ResizeObserver 读取由自身撑开的父高度，形成持续增长。
- 值日完成按钮按任务 ID 隔离组件生命周期，快速切到另一任务时不继承前一个任务的灰色完成背景或成功态。完成稳定性采样在任务标题真正完成过渡后开始，保留原位不抖动断言。
- 球球提示与实际设置入口一致。统一按钮按压缩放改为 0.96，保留回弹。
- 浏览器检查适配 112px 登录球球、正式设置入口和日期分页。日期分页仍逐页核对所有历史记录、详情抽屉、修正权限和编辑保存；没有删去历史编辑验收。
- 导航弹簧检查明确走无 WebGL 降级路径；邮箱 HTTPS 检查另外验证实际导航的光学或 CSS 渲染、三条可访问链接及窄屏布局。
- 球球隔离页面显式使用 UTF-8，并核对表情中文名称，避免经典脚本在测试文档中误解码。
