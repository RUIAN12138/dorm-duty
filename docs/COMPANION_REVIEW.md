# 球球交互与固定抽屉验收

基于 main b6dbc827（已合并 #58），保留维护者的离线恢复修复。设置入口为“更多 → 球球设置”，账号/宿舍与低频操作分层收起。

## 用户路径

1. 登录/注册：中上方原版球球跟随非敏感输入光标与点击位置；密码和一次性验证码固定回避视线，不读取密码文本来测量光标。
2. 登录成功：只记录球球几何位置，值日页球球680ms连续移动/缩小到左上角，随后上到下渐显内容；后台、减少动效与卸载释放过渡。
3. 设置：球球预览和操作保持常驻，32种表情按需展开；短抽屉自然高度，正文滚动不卷走标题/拖动条，名单独立滚动继续保留。
4. 球球单击打开留言草稿，双击取消单击并互动。用户明确选择接收人并确认发送；留言1–120字，接收人和宿舍隔离，15秒限频，复用已有提醒表与通知/已读流程，无新增迁移。
5. tips每段20字、总计40字，最多两段；小气泡不超过154px，点击可收起。模型适配器只接收scene/intent，尚未配置硅基流动、密钥或外部模型调用。
6. 室友消息浮窗缩小至350px上限，轻量毛玻璃/圆角，不透明降级；收起/展示仍不自动标为已读。
