# 可用性与交互改进

2026-10-15。针对任务文字迟缓、抽屉拖沓、换宿舍丢入口、菜单过杂、找不到轮序及误触无法撤销。本轮保留黑白大字、三页导航，不增加前端依赖。已随 PR #18 发布为 `20261015-usability-v21`；发布详情见 [当前进度](PROGRESS.md)。

## 可直接验收的入口

1. **任务标题**：连续点「地板 / 洗手池 / 厕所」，文字立即更新，不等旧文字退出。稳定 DOM 只做 140ms 的 3px 位移，透明度最低 0.72，不从零淡入。
2. **抽屉**：抬水「查看任务」从屏幕下边进入，底层不变暗、导航仍可点；下拉松手可以归位，向下关闭。其他编辑 / 设置面板默认模态，保留焦点、滚动锁、遮罩和返回栈。底层整页不再同时缩小。
3. **宿舍切换**：「… → 切换宿舍 → 我的宿舍」点已加入宿舍卡片，恢复原成员及设备权限，无需再次输入邀请码。首次加入仍需显式填写，分享 URL 不代替加入。最多保存 12 个宿舍；浏览器存储不可用时仍可完成当前访问。
4. **轮序**：顶部独立「轮序」图标，创建者长按拖动、邻居让位，显式保存；普通成员查看名单。当前抬水者保持，下一次按新顺序轮换。接口仍校验创建者与版本。
5. **精简菜单**：第一层为身份、提醒 / 消息 / 换宿舍 / 通知四张卡片，创建者另有任务设置。低频选人、标记、创建、恢复、刷新放入「个人与更多」。菜单项有图标、触摸面积与短交错入场。
6. **打卡撤销**：本人完成后，原按钮变为带「撤销」的回执；抬水推进下一人后保留最近一次撤销入口。日历日期详情中也可撤销本人记录。接口确认后恢复待办、日历移除对应完成标记；再次完成仍可正常推进。

撤销只允许本人。自由轮次 / 抬水若后续轮次已有室友完成，则拒绝回退，避免抹掉后续记录；任务已暂停或安排方式已改变也会提示。首页提供近 24 小时的近期入口，历史记录不由前端擅自改写。撤销采用既有版本与事务守卫；更高的未完成轮次标为 cancelled，保留外键引用，不删除任务。日历订阅和定时提醒查询也回到恢复后的当前轮次。

## GitHub 参考与实现方式

- [Motion for Vue](https://github.com/motiondivision/motion-vue)：沿用锁定的 2.7.0，用于选中背景、布局与抽屉。抽屉完整 transform 走元素动画，拖动和反向共享姿态，避免六个值分帧更新。
- [Reka UI](https://github.com/unovue/reka-ui)：沿用 2.11.0 Dialog / Tabs，提供焦点、嵌套与模态基础，没有更换为尚不稳定的抽屉实现。
- [OpenAI Apps SDK UI](https://github.com/openai/apps-sdk-ui)：参考其简洁层级、图标触摸区域和分组操作方式；它是 React 组件，本项目按 Vue 实现，没有复制为依赖，也不将其称为 GPT 原生 App 源码。
- 本地 React Bits 的 Dock / AnimatedContent / BlurText 仅作审阅参考，没有引入 React、GSAP 或逐字模糊效果。指定的 awesome-design-md 与 math-curve-loaders 目录当前不存在，未声称使用。
