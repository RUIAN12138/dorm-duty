# 演示与录屏准备

## 本地运行

安装 Node.js 22.13 或更新版本，在仓库根目录执行：

```bash
./scripts/setup.sh
npm run web:dev
```

访问 `http://127.0.0.1:8081/`。本地数据与正式服务器独立；展示前使用专门的演示宿舍及虚构成员，不展示邮箱、邀请码、个人聊天或正式业务记录。首次运行、外部服务与设备能力以当前环境为准。

已有素材包括五张隔离测试截图和一段 25 秒的教程练习自动化录屏；录屏位于本机 `data/resume-portfolio/video/tutorial-practice.mp4`，不在 Git 仓库中，展示的是模拟数据和浏览器自动操作，并非真人或真机录屏。

## 建议录制 60–90 秒讲解视频

1. **0–10 秒：问题与首页**。介绍共同生活中谁做、何时交接、哪里查看的问题；展示当前任务和轮次。
2. **10–25 秒：任务与提醒**。切换任务，展示一轮状态与提醒入口；演示数据必须隔离，不实际通知真实室友。
3. **25–40 秒：创建与预览**。展示创建草稿、配置任务与复用正式页面的交互预览；说明预览不写入正式业务。
4. **40–55 秒：球球与教程**。演示练习模式及基于当前身份的数据查询；不要展示真实个人信息。
5. **55–75 秒：技术亮点**。用架构图解释服务端权限、任务轮次、预览数据服务和自动化测试。
6. **最后：验证边界**。指出浏览器测试与实际设备验收分别进行，诚实说明未验证内容。

这是一份待录制脚本，不代表完整视频已经制作。录制时添加字幕并核对内容，无需展示任何令牌或后台私人数据。
