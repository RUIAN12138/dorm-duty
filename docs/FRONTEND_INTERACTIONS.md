# 前端交互、组件与动效清单

核对日期：2026-10-15。基于正式网站 v19 及对应源码。编号用于逐项提出修改，例如「I05 按住时放大选中标签」「A10 关闭时去掉回弹」。本清单记录当前行为，不把曾经提出但尚未启用的设计算作已实现。

**技术和范围**

- Vue 3 + TypeScript + Vue Router + Pinia + Vant 4；PWA 使用 vite-plugin-pwa / Workbox。
- 动效使用 CSS transition / keyframes、Vue Transition、requestAnimationFrame 和 Web Animations API。没有引入 Framer Motion、GSAP 或 React 动效组件。
- 当前主入口是 `GuestHome.vue`，承载 `/`、`/water`、`/calendar`；线上 URL 前缀是 `/dorm-duty/`。
- 共有 19 个自定义 Vue 组件：15 个服务当前免账号入口，4 个服务保留的旧账号版。另有 App.vue 和 8 个页面文件。
- 原生 Android / HarmonyOS 客户端加载同一个正式网页，因此主界面的这些组件和动效共用。原生系统权限弹窗、系统通知和系统启动动画不属于这里的网页动画。

**可优先逐项统一的地方**

1. A04 与 A14：底部导航和两段切换条的拉伸比例、动力学不同。
2. A08 / A09 / A10：普通抽屉、共享元素、抬水专用抽屉使用不同进出逻辑；A10 退出的 102% / 96% 回弹可单独决定是否保留。

4. A02 / A06：整页与任务标题分别使用水平和垂直过渡，手势方向与视觉方向可统一审查。
5. I25 / I26：设置面板、排序、保存是最复杂的一组交互，修改时要保留取消与版本冲突处理。
