# 前端交互、组件与动效清单

核对日期：2026-10-15。本轮源码已完成菜单、身份回访、撤销和运动细节改进，正式发布状态见 PROGRESS.md。编号用于逐项提出修改，例如「I05 按住时放大选中标签」「A10 关闭时去掉回弹」。本清单记录当前行为，不把曾经提出但尚未启用的设计算作已实现。

**技术和范围**

- Vue 3 + TypeScript + Vue Router + Pinia + Vant 4；PWA 使用 vite-plugin-pwa / Workbox。
- 底栏、分段、抽屉和排序使用 Motion for Vue 2.7.0；Reka UI 2.11.0 负责无样式 Dialog / Tabs 语义与焦点。其余既有 CSS / Vue Transition / WAAPI 动效保留。本轮保留黑白、大字任务和三页结构，重排菜单与任务操作。
- 当前主入口是 `GuestHome.vue`，承载 `/`、`/water`、`/calendar`；线上 URL 前缀是 `/dorm-duty/`。
- 共有 29 个自定义 Vue 组件：25 个服务当前免账号入口，4 个服务保留的旧账号版。另有 App.vue 和 8 个页面文件。
- 原生 Android / HarmonyOS 客户端加载同一个正式网页，因此主界面的这些组件和动效共用。原生系统权限弹窗、系统通知和系统启动动画不属于这里的网页动画。
