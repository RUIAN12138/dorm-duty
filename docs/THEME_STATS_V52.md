# v52 页面布局、单色统计与主题稳定性

## 行为

- 保留黑白大字，值日主体下移至略高于屏幕中心；短屏仍使用紧凑布局，抬水主体位置不改。
- 暗色玻璃使用暗色镜片，染色位于文字后方，保留选中文字对比度。CSS 降级与 WebGL 使用同一套色值。
- 日夜切换不再截取整页 WebGL/毛玻璃快照；保留太阳/月亮按钮自身动效和正文轻过渡。玻璃保存静态绘制缓冲，主题文字颜色过渡期间同步刷新采样，不靠无限动画保活。顶部浏览器主题色按用户要求保持白色。
- 统计卡片默认每 5 秒自动翻到下一张，手动触摸/键盘操作后暂停 30 秒，切页后仍保留选中卡片和暂停期限。后台、操作抽屉、减动效时停止自动翻页；重新打开应用重新开始。
- 统计颜色改为单一灰色基色随距上次完成时间连续加深，达到该任务间隔两倍时到最深；夜间用同一基色推导。颜色入口仅自定义一个基色，在当前设备保存，日夜共用；文本自动选黑白以保持对比度。间隔继续由创建者按任务设置并由服务器保存。
- 只将 CompactRecordList 恢复为 v50 的按日折叠记录、层叠边缘和渐进收起/跟随 FLIP，保留列表分页、滚动与展开记忆。日历、统计和其他 v51 功能继续保留。
- 所有 ElasticSheet 上限为 75dvh；短内容按需收缩，长内容在固定标题/关闭按钮下独立滚动，固定底部保存按钮保持可达。

## 参考与边界

参考本地 React Bits Stack / Carousel 的叠卡和自动播放思路，继续使用现有 Vue 组件；未新增依赖、后端接口、数据库迁移或生产配置。awesome-design-md 与 math-curve-loaders 的已配置路径在本机不存在。沿用 docs/FRONTEND_MOTION_CONTRACT.md 的完成、撤销、圆环/+1 与抽屉动效约定。
