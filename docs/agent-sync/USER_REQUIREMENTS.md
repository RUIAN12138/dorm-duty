## 新宿舍：配置型创建流程

- **现有宿舍绝不自动迁移或重置**：成员、历史打卡、轮序、任务数据、页面及通知原样保留。新流程优先仅用于新建宿舍，配置版本隔离。已有宿舍共用组件仅允许被明确提出的纯视觉修复。
- 创建者只创建宿舍、定义任务及规则、配置页面与预览；无须提前选择成员或填写舍友名单。舍友凭邀请码并完成原有邮箱认证后自行输入姓名、绑定自己的稳定成员身份；防重名／冒领／重复绑定。
- 新创建流程 **最多五个主要页面**，**每页一个核心问题、最多 1–2 项设置**。大字、黑白极简、充分留白；不再出现一屏十余输入项或多段冗余说明。内容较多时使用卡片切换／横向分段，不要求常规手机垂直滚动才能看到全部内容。小屏与无障碍字号不可裁掉关键操作。
- 每个任务可自定义名称／内容／规则；创建者决定哪些任务放值日页（至多四项）、第二任务页或催促页，可编排导航顺序；日历随真实任务及完成记录自动生成。
- 配置步骤必须允许随时返回／直接跳转而不丢草稿。顶部有球球、与步骤相关的简短 Tips 与动画。文本／密码聚焦时球球视线处理，密码输入时闭眼（仅若该页面确实有密码框）。
- UI 不使用“硬性／软性”命名。提问“任务按什么节奏完成？”，可选“大家做完再开始下一轮”“按时间安排”“做完交给下一位”；底层分别为 self_round / scheduled / completion。仅在按时间安排时出现简洁的 iOS 风格时间滚轮。
- 创建向导进度条按上方最新用户指令执行：**平时只有粗线轨道和五个极简节点，玻璃滑块仅在触碰/按压时出现并可拖动，释放后隐藏**；页面和球球 Tips 实时联动，触感在支持的平台有效，不支持自然降级；无数字、文字、刻度尺或额外符号。
- 预览是**完整屏幕直接复用正式 App** 的任务页、导航、卡片、详情和日历组件，只替换为沙箱草稿数据；不是另做模拟 UI。可在预览中长按拖动底部导航顺序，实时同步草稿。预览任何操作不能写真实业务数据或发送真实通知。
- 新版值日页**完全沿用正式值日页**的顶部横向任务切换、大字任务、完成按钮与轮次进度，不要另做一套卡片 UI。
- 创建完成时，球球沿连续轨迹移至正式首页左上角，标题、任务卡、底部导航错峰从下方浮现。动画要跟手、可中断、不过度。
- 新手引导是独立正式页面（欢迎滑动、胶囊页码、球球动画、功能聚光灯、空状态、权限申请前说明），可跳过，进入正式 App 后不反复打扰。
- 新宿舍的“宿舍任务设置”采用同样的轻量分步／卡片编辑，不再沿用密集长表单。
