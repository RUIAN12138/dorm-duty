# 球球聊天与提醒

用户已明确聊天外观、长按入口、20字短消息与任务提醒，并于提供智谱模型配置后要求继续实现。

- 服务端代理智谱 glm-4.7-flash，关闭推理输出；使用 JSON 消息、表情与提醒提案。只给模型当前宿舍、任务与近期对话，不传邮箱、token、邀请码、配置密钥。聊天记录按宿舍及成员隔离，保留最近100条；有清空入口。
- 球球人格：温和、机灵、可靠，主要回答应用使用；消息每条至多20个Unicode字符，最多6条，不宣称尚未执行的提醒。表情限定现有引擎白名单。思考提示是界面等待状态，不展示模型思维链。
- 长按550ms进入，移动超10px取消，结束抑制click；原单击留言／双击互动不变。球球由原位置向顶部中央移动，顶端至少安全区+48px；关闭反向。背景暗色+静态毛玻璃，不动画blur；仅此层覆盖旧无模糊约定。
- 默认文字，左侧圆形黑色麦克风／右侧白色玻璃输入胶囊；语音模式左右宽度互换，通过布局FLIP保持文字与图标不变形。语音胶囊开始／停止录音，文字圆形只恢复文字。录音至多30秒，浏览器转16k单声道PCM WAV后交智谱glm-asr-2512转文字，确认后发送。不持久化音频。
- 消息在球球与底栏之间独立滚动，弹性渐进入场。输入跟随visualViewport软键盘，焦点限制在模态，Esc／返回／关闭反向退出，关闭停止麦克风；后台／身份切换中断请求及录音，减少动效直接终态。
- 聊天提案只能设置一次性提醒：未来30天内，明确具体日期、时间、有效的本人或单个本宿舍室友；不明确先追问。提案经用户点击确认后持久化。调度复用现有站内／推送／邮箱队列，原子去重，发送时重新检查双方成员与邮箱绑定；失败不谎报成功。支持取消尚未发送的计划。
- API与录音按成员限流，HTTP body有大小上限、上游有超时和错误脱敏，密钥仅私密配置。未配置服务清楚显示不可用，绝不以假回复冒充模型。
- 验证：模型模拟只用于隔离测试，真实提供商验收另列；聊天权限、撤销、超时、重复请求、队列、语音WAV边界；两浏览器中间帧、长按取消、两种输入形变、窄屏与暗色、返回、失败、减动效。真实麦克风/系统权限和提供商Key需设备/实际配置验收。
