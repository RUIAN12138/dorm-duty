# v54：统计配色与前台消息去重

## 修改范围

仅修改本轮指定内容：统计日间中性灰/夜间灰白及自然变色、消息浮窗遮挡与宽度、接收方前台已收到时不再补发邮件。保持原圆形主题切换、卡片堆叠/自动播放、导航、标题/按钮间距、完成/撤销、抬水交接与轮序规则。版本提示只更新本次变化清单。

## 统计

日间默认 #e0e0e0 → #aaaaaa，稳定使用深色文字；夜间保留 #f2f2f2 → #b0b0b0，使用深色文字。深度在归一化间隔上使用 smoothstep，缓入缓出且连续单调加深；旧默认灰/棕黄色配置迁移到新灰黑默认，其他自定义保留。卡片背景320ms、文字220ms，预览使用同一过渡；减少动效直接终态。

不改主题控制器；圆形主题快照事件到来时只结束卡片自身的颜色过渡，以新主题的最终色进入圆形展开，避免展开结束后再跳一次颜色。非圆形的系统/无API变色沿用卡片自身过渡。

## 消息浮窗

消息位置/文字/弹性进出与拖动保持。宽度从 min(342px,100%-32px) 到 min(390px,100%-24px)。仅消息浮窗增加稳定的实色遮挡底层，保留玻璃边缘，移除该运动层的 backdrop-filter，避免 WebKit 新增运动层时底层文字叠穿；导航与其他玻璃不变。

## 应用内接收与邮件

新增追加迁移0016，为提醒添加 nullable 的 in_app_received_at。接收回执与 read_at 独立。

- 只有实际展示完消息浮窗，或用户在前台打开消息列表，才调用 PATCH /chores/reminders/:id/received；后台、游客和其他身份不能代确认。
- 服务器复用成员会话和宿舍授权，校验接收人、幂等记录首次接收时间，并取消该消息尚未发送的邮件。前台回执失败时保留邮件后备，当前浮窗可随原10秒轮询重试；不弹额外错误打断用户。
- 邮件对新提醒留20秒接收窗口，随后沿用原10秒队列周期；未收到回执则正常邮件发送，旧客户端同样保留邮件后备。测试邮件和验证码即时路径不变。窗口从消息创建时间算起，重启不重新等待。
- 队列发送前再次验证回执；回执及取消跨重启持久化。不把展示自动标成已读、不关闭系统推送。SMTP已接受的邮件无法撤回。

## 验证与发布

统计连续深度/文字对比、真实颜色中间帧、圆形展开结束无第二次变色、浮窗遮挡/宽度、真实前台展示回执：Chromium和WebKit隔离浏览器检查。
check-in-app-email：默认20秒窗口、本人/跨成员/跨宿舍/匿名权限、幂等、展示不等于已读、取消待发、后台邮件后备、邮件包含催促人、先回执后入队、重启保持、已发不可撤回。使用隔离SQLite及假SMTP。

发布前备份；0016仅追加新列，不修改旧迁移或历史记录。回滚可切回v53代码并保留新列，禁止删库或删除新列来回滚。实体iPhone合成流畅度和真实邮箱投递不由自动化浏览器测试代替。
