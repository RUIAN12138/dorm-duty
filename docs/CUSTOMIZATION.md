# 排班与值日内容自定义

2026-10-12 更新。当前主页的地板、厕所、抬水在「自定义任务」分别配置，详细规则见 [CHORES](CHORES.md)：每类内容与时间独立，地板 / 厕所按日期轮换，抬水完成后轮换；正式成员领取限定身份后可以完成本人任务与定向提醒。只有持完整管理令牌的创建者可以修改设置。

下文保留原 `/duties` 排班的任务模板、休息日、单日修改和接口，适用于原管理路由，不会自动修改新版三类任务。创建者可从主页页脚「宿舍成员管理」进入原管理页面；成员限定令牌不能调用这些管理接口。

## 可配置内容

| 配置         | 范围与行为                                                     |
| ------------ | -------------------------------------------------------------- |
| 默认值日内容 | 1 至 200 字，可换行；值日任务保留当时的内容快照                |
| 默认截止时间 | 00:00 至 23:59，按 Asia/Shanghai 保存及展示                    |
| 轮换顺序     | 所有有效成员恰好出现一次，用上移 / 下移调整                    |
| 起始日期     | 对应第一位成员的首个轮换名额；日期早于起点时按同一循环向前计算 |
| 连续负责     | 每人连续负责 1 至 14 个实际值日日期                            |
| 每周值日日期 | 星期一至日自由组合，至少选一天；未选择的星期不消耗轮换名额     |
| 排班范围     | 7、14、30、60 或 90 天；API 支持 7 至 90 天的规则范围          |
| 每周任务模板 | 星期一至日分别覆盖内容、截止时间；留空时继承默认值             |
| 指定休息日期 | 最多 180 个日期；休息日期不消耗轮换名额，已完成记录不删除      |

例：只选周一至周五，连续负责 2 个值日日期，周三设为休息。第一位室友负责周一、周二；第二位负责周四、周五；下一周接着轮换。

服务端计算未来一周的草稿预览。预览不修改数据库，保存规则才会更新明天起的未完成任务。保存会覆盖未来未完成的手工安排，操作前有明确确认。今天、过去与已完成记录保留。

Worker 在访问已开始排班的宿舍或消息接口时，按配置范围补齐未来空缺，不覆盖已有任务；未开始排班的宿舍保持空。缩短范围不会自动删除已有其他未来任务；休息日移除重排范围内未完成任务。历史通知保留文字，取消任务的通知解除关联。原 Python 的每分钟进程没有自动迁入云端，Cron 和 Push 待配置。

## 单独修改某一天

进入「排班」，选中日期，点击「自定义这一天」。可同时修改成员、内容和截止时间，不影响其他日期。没有排班的日期可点击「添加这一天的安排」，包括平时设为休息的日期。补齐排班保留手工安排；主动重排会覆盖范围内的未完成安排。

「生成 / 补齐排班」可以选择开始日期与天数。生成范围限制在今天至未来 90 天；重排从明天或之后开始。过去及已完成任务不能编辑，普通成员只能查看。

## 接口

- `PATCH /dorms/current`：新增 `schedule_rules` 字段，完整规则 JSON；仍需要 `expected_version`。
- `POST /duties/preview`：管理员传入轮换顺序、开始日期、默认内容 / 时间、规则及预览区间，返回逐日预览。使用与生成相同的计算函数。
- `PATCH /duties/{id}`：可选 `assignee_id`、`task_text`、`deadline_time`，至少提供一项；仍需要版本号。
- `POST /duties/custom`：管理员为未安排日期添加任务，需要日期、成员、内容、时间和版本号。
- 原有生成与重排接口继续兼容，后台补齐改为读取宿舍配置范围。

Alembic `0002` 仅给宿舍表增加 JSON 规则列，已有宿舍保留默认的每日轮换、30 天和一天一人。

## 动效与可访问性

2026-10-12 新版采用黑、白、中性灰，值日 `/`、抬水 `/water`、日历 `/calendar` 分为三页，底部导航切换，各页只显示一项主要内容。100 个原创成员标记用硬边像素和轻微绿色荧光显示，图案静态，不循环播放；来源与稳定 ID 见 [MEMBER_MARKS](MEMBER_MARKS.md)。加载、错误、空状态和减少动态效果保留。以下为原管理组件动效说明。

首页卡片用 Pointer Events 和帧内弹簧计算小幅倾斜及触点高光；纵向滚动不被拦截。列表项展开到详情抽屉，关闭时反向收缩。抽屉拖拽支持上推阻尼、下拉位移 / 速度判断及回弹，另有关闭按钮和 Escape 键入口。按钮按压缩小，列表错峰入场，卡片边缘有轻微呼吸光。

跟随系统浅 / 深色模式。减少动态效果时停用倾斜、入场、回弹与呼吸动画；减少透明效果时提供实色表面。手势同时保留按钮及键盘入口，抽屉限制焦点并在关闭后恢复来源焦点。
