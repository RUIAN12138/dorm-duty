# 按钮反馈与视觉对齐

2026-10-15。本轮遵循用户最新约束：保留黑白、大字和抬水页原有布局；功能解释采用按需小提示，避免常驻说明。发布状态见 [当前进度](PROGRESS.md)。

## 最终行为

- 本人打卡后，整块按钮显示「已完成 / 已抬水」，再次点击恢复待办。不额外放「撤销」按钮，沿用现有本人权限、后续轮次保护与版本守卫。
- 日历日期详情和列表使用同一记录行：个人标记、名字与任务左对齐，时间 / 完成状态右对齐。本人已完成行可再次点击恢复，其他成员记录为只读。
- 移除打卡成功与撤销成功的中央浮层，以按钮状态反馈。其他必要的短提示使用白底、细边框、圆角、顶部位置，不覆盖主要任务按钮。
- 完成按钮按住时纵向压缩至 0.94、横向轻展至 1.025，松手通过既有 Motion 弹簧回位；轮次、日历导航、日期、排序操作有对应轻微按压反馈。催促姓名沿用原大字和波纹 / 浮字，优化为轻微形变和回弹，键盘与减少动态效果不播放装饰动画。
- 地板 / 洗手池 / 厕所的轮次面板可分别调整成员排列，创建者长按拖动、邻居让位，显式保存。自由打卡规则、轮数、已完成状态和历史记录保持；普通成员看到同一保存顺序。
- 日历统一七列轨道，今日数字有独立圆形状态，有记录日期轻填充，个人标记继续区分值日 / 抬水。列表按日期分组，不重复堆日期或功能解释。
- 首次入口及邀请码表单围绕视觉中心布局，主操作同宽、次要入口归并为一排；长宿舍列表和长创建表单仍自然滚动。表单标题旁问号打开居中小提示，不挤动页面。提示用独立标题 / 正文 / 确认区，背景为半透明玻璃蒙版；点蒙版、关闭、知道了、Esc 或原生返回均可收起。创建权限说明也收进小提示。
