## 新版本地手机验收

1. 在 Mac 的项目目录运行 `./scripts/local.sh --open`，电脑打开 [http://127.0.0.1:8081/](http://127.0.0.1:8081/)。默认数据保存到 `data/dorm-local.db`，不是此前重启清空的内存预览。
2. 手机与 Mac 连接同一 Wi-Fi，使用启动器输出的 `http://局域网IP:8081/` 地址。手机上的 `127.0.0.1` 指向手机自身，不能用于访问 Mac。
3. 首次先创建或加入宿舍，无需账号密码。创建者选择自己的像素标记；室友输入邀请码、选择名字与未占用标记并确认。「值日」`/` 只显示本人今天的地板 / 厕所任务，无当天任务时显示最近未来任务。底部「抬水」切到 `/water`，「日历」切到 `/calendar`，每页保持一种主要内容；创建 / 加入 / 选人步骤不显示底部导航。
4. 创建者从值日或抬水页的次级操作入口打开「自定义任务」，修改地板、厕所、抬水各自的内容、截止时间、开始日期、顺序和启用状态；地板 / 厕所还可设置星期及连续负责天数。换用另一浏览器选择创建者名字，只能得到成员身份，不应显示创建者管理权限。
5. 成员点击本人「我已完成值日」；当前抬水负责人点击「我已抬水」，服务器记录时间并自动交给下一位。另一台手机刷新核对完成时间和负责人。验证重复点击不产生第二条记录，其他成员不能完成这项任务，未来开始任务不能提前打卡。
6. 从底部打开「日历」，点击完成日历中的日期，检查对应成员独特的像素标记、任务和服务器完成时间。不同成员完成显示不同标记，多条完成可在日期详情查看；更换标记后旧记录不改变。跨日补做按上海时区实际完成当天标记。
7. 一位成员在值日或抬水页点击「提醒室友」选择另一人及其未完成任务；接收人在网页打开或刷新后，从三页共用「室友消息 N」入口打开抽屉查看并标记已读；日历页不显示发提醒和任务设置操作。同一人对同一室友同一任务连续提醒被一分钟限频；不能给自己或已完成任务发提醒。
8. 修改规则后检查地板 / 厕所从明天起重排、今日与完成历史保留；抬水当前负责人继续本轮，内容和时间更新。停止并重新启动服务后，检查邀请码、规则、图案、当前抬水轮次、已完成记录及对应浏览器身份恢复。
9. 分别刷新和直接打开 `/water`、`/calendar`，确认页面路径、成员身份与对应主内容恢复；用底部导航及浏览器返回 / 前进切换，底部不遮住最末操作。
10. “先用游客模式体验”才进入六人 `6-402` 示例，持续显示游客标记；默认项只用于只读验收，不自动代替真实宿舍，不能写入完成或提醒。

详细操作与存储边界见 [本地使用说明](LOCAL_USAGE.md)。Mac 必须保持运行、联网且服务开启；这一局域网 HTTP 入口不是公网 HTTPS。手机 HTTP 入口不用于确认 PWA 安装、通知权限或锁屏 Push，也没有证明两台实体 iPhone 已完成同步验收。

### 旧版手机使用步骤

1. 使用 Safari 打开上述 HTTPS 地址，注册账号或登录已有验收账号。
2. 创建宿舍，在“宿舍管理”复制邀请码，室友在另一台手机注册并加入。
3. 管理员设置轮换顺序、值日星期、连续轮值天数、跳过日期、每日任务与截止时间，预览后保存；在“排班”生成或补齐排班。
4. 当天执行人完成打卡，另一名成员刷新首页和历史记录核对结果。
5. 需要桌面图标时，在 Safari 分享菜单选择“添加到主屏幕”，从图标再次打开应用。

可以通过 Wi-Fi 或手机流量打开公网 URL，无需连接同一局域网。当前后端使用本机演示数据库，跨设备读取相同服务器数据；请将其作为验收环境使用。账号登录状态保存在当前页面会话，刷新可恢复，关闭页面或重新打开主屏幕应用后可能需要重新登录。

### 旧版运行边界

该地址由 Cloudflare Quick Tunnel 转发到 Mac 上的正式网页构建及 FastAPI。Mac 必须保持运行、联网，相关服务与隧道进程必须保持开启。电脑休眠、关机、断网或隧道停止会中断访问；重建隧道会生成新的域名，原二维码也需要更新。[Cloudflare Quick Tunnel 说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

长期云端方案使用 `docker-compose.yml` + `docker-compose.https.yml`，包含数据库迁移、API、唯一提醒 worker、Nginx 与 Caddy HTTPS 入口。配置和操作方法见 [部署说明](DEPLOYMENT.md)。当前没有指定云服务器 / 托管账号和域名，该路径尚未实际上线。
