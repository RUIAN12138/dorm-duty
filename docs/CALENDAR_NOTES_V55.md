# v55 定向修复

## 范围

保留黑白大字与现有排版、完成按钮收圆/描勾/粒子、圆环/+1、抽屉、抬水交接、主题展开和导航玻璃。仅修改本轮四项。

## 行为

- 成功打卡回执立即投影到日历，日期按 Asia/Shanghai（UTC+8）计算；不等待后续读取。撤销清掉中心与邻月副本。失效写前读取，拒绝旧版本响应。进入日历同步读取，保留失败时已确认数据。服务器仍为最终数据源。
- 统计纯白起点，每满24小时增加1/30灰度，默认日间每档2–3个RGB值，30天到#aaaaaa；夜间30天到#b0b0b0。暂无记录保持白，未来时间按刚完成处理。任务的提醒间隔设置不再影响颜色速度，原自定义终点保留。
- 跨两个页签点击时直接定位镜片到目标页，不扫过中间项；相邻弹簧与拖动切页保持。页面沿用原来的渐显过渡。
- POST /chores/notes 接受 target_member_id 为单个成员ID或字符串 all。all只取当前宿舍除本人外的有效成员，整体事务提交，每条独立mutation_key、独立读/接收回执和推送队列。任何目标在15秒冷却中时整个请求拒绝，不部分发送。单人返回保持兼容，群发返回recipients和reminders。单人宿舍群发返回422。

## 验收

隔离数据库：群发只发本宿舍其他人，每人一条；重试不重复、匿名/跨宿舍无权；日历收据去重、UTC+8跨日、撤销邻月同步。浏览器：后续读失败仍立即出现热力格与详情、撤销清除、首尾点击不经过中间页及镜片、群发入口真实送达。Chromium/WebKit与既有完成/主题回归分开记录。
